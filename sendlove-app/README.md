# Send Love - The Glyph Gate

A digital portal for transmitting love in all its forms. Send love through monetary energy, words & feelings, or physical gifts.

## Features

- **Send Love Portal**: Main landing page featuring the iconic sendlove.png butterfly envelope
- **Love Transmission**: Three modes of sending love:
  - 💰 Monetary Energy
  - 💕 Words & Feelings
  - 🎁 Physical Gifts
- **Love Glyphs**: Unique procedurally generated 3D love glyphs using Three.js
- **Beautiful Design**: Magenta/pink gradient aesthetic with floating animations

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Three.js / React Three Fiber
- Radix UI Components

## Getting Started

```bash
# Install dependencies
npm install
# or
pnpm install

# Run development server
npm run dev
# or
pnpm dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the portal.

## Deployment

This app is configured for deployment on Vercel. Simply connect your repository to Vercel and it will automatically deploy.

## Routes

- `/` - Landing page with Send Love portal
- `/love` - Love transmission interface with three sending modes
- `/garden` - Additional portal feature
